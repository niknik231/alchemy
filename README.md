# ⚗️ Алхимия

Игра о создании новых элементов из сочетаний уже открытых. Начни с четырёх базовых — **вода**, **огонь**, **земля**, **воздух** — и открывай всё новые и новые, перетаскивая элементы друг на друга.

## 🚀 Быстрый старт

Просто открой файл `alchemy.html` в браузере — никакого сервера не нужно. Игра полностью standalone: все данные, стили и скрипты встроены в один HTML-файл.

## 🖥️ Разработка (dev-сервер)

Если вы правите файлы в папке `alchemy-refactored/` и хотите видеть изменения в браузере без постоянной пересборки `alchemy.html`:

```bash
cd alchemy-refactored
python serve.py
```

Сервер поднимется на `http://localhost:8000/` и автоматически откроет браузер.  
Поддерживаются `fetch`-запросы к JSON-файлам, поэтому модульная версия работает полноценно.

Чтобы остановить сервер — нажмите `Ctrl+C`.

После завершения правок не забудьте пересобрать standalone:

```bash
python build-standalone.py
```

### Что где хранится

| Файл | Содержимое |
|------|-----------|
| `alchemy-refactored/data/elements.json` | Каждый элемент: `id`, `name`, `icon` (emoji или svg), `category`, `hint` (подсказка), `iconType` (`emoji` / `svg` / `full`), `isBase` (базовый ли) |
| `alchemy-refactored/data/recipes.json` | Массив троек `["ингредиент_A", "ингредиент_B", "результат"]` |
| `alchemy-refactored/data/categories.json` | Категории: `id`, `name`, `color`, список элементов |
| `alchemy-refactored/data/icons.json` | SVG-иконки для элементов с `iconType: "svg"` |

## ➕ Как добавить новый элемент

> ⚠️ **Важно:** после изменений в `alchemy-refactored/data/` нужно пересобрать `alchemy.html` командой:
> ```bash
> python build-standalone.py
> ```

### Шаг 1: Добавь элемент в `alchemy-refactored/data/elements.json`

```json
{
  "id": "neon",
  "name": "Неон",
  "icon": "💡",
  "category": "science",
  "hint": "Инертный газ, светящийся при прохождении тока",
  "iconType": "emoji",
  "isBase": false
}
```

**Поля:**
- `id` — уникальный идентификатор (латиница, без пробелов)
- `name` — отображаемое название
- `icon` — emoji-символ или SVG-разметка
- `category` — ID категории из `categories.json`
- `hint` — подсказка, показываемая в игре
- `iconType` — `emoji` (просто символ), `svg` (SVG из `icons.json`) или `full` (крупный emoji)
- `isBase` — `true` только для стартовых элементов (вода, огонь, земля, воздух)

### Шаг 2: Добавь рецепт в `alchemy-refactored/data/recipes.json`

```json
["electricity", "gas", "neon"]
```

Порядок ингредиентов не важен — движок сам отсортирует их по алфавиту.

### Шаг 3: Пересобери standalone

```bash
python build-standalone.py
```

Готово! Теперь `alchemy.html` содержит новый элемент.
