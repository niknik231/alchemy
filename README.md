# ⚗️ Алхимия — Рефакторинг

Модульная версия игры «Алхимия» с удобной структурой данных для добавления новых элементов.

## 📁 Структура проекта

```
alchemy-refactored/
├── index.html              # Главная страница (минимальный HTML)
├── css/
│   └── styles.css          # Все стили игры
├── js/
│   ├── engine.js           # Игровой движок (логика, сохранения, комбинирование)
│   ├── ui.js               # UI (отрисовка, drag-and-drop, события)
│   └── add-element.js      # Хелпер для добавления элементов через консоль
├── data/
│   ├── elements.json       # Все элементы игры (879 шт.)
│   ├── recipes.json        # Все рецепты (1088 шт.)
│   ├── categories.json     # Категории элементов (14 шт.)
│   └── icons.json          # Кастомные SVG-иконки
└── serve.py                # Локальный сервер для тестирования
```

## 🚀 Запуск

```bash
python serve.py
```

Откроется браузер по адресу `http://localhost:8000/`

> **Важно:** Игра загружает данные через `fetch()`, поэтому требуется локальный сервер. Простое открытие `index.html` в браузере напрямую не сработает.

## ➕ Как добавить новый элемент

### Способ 1: Редактирование JSON (рекомендуется)

#### 1. Добавь элемент в `data/elements.json`

```json
{
  "id": "neon",
  "name": "Неон",
  "icon": "💡",
  "category": "science",
  "hint": "Инертный газ, который светится при прохождении электрического тока.",
  "iconType": "emoji",
  "isBase": false
}
```

Поля:
- `id` — уникальный идентификатор (латиница, без пробелов)
- `name` — название на русском
- `icon` — эмодзи или текст иконки
- `category` — ID категории (см. `data/categories.json`)
- `hint` — подсказка для игрока (опционально)
- `iconType` — `"emoji"` | `"svg"` | `"full"`
- `isBase` — `true` только для 4 базовых элементов

#### 2. Добавь рецепт в `data/recipes.json`

```json
["electricity", "gas", "neon"]
```

Формат: `["ингредиент1", "ингредиент2", "результат"]`

Порядок ингредиентов не важен — движок сам отсортирует.

#### 3. Обнови категорию (если нужно)

Если создаёшь новую категорию, добавь её в `data/categories.json`:

```json
{
  "id": "my_category",
  "name": "Моя категория",
  "color": "#ff5733"
}
```

### Способ 2: Через консоль браузера (для быстрого теста)

1. Запусти игру
2. Открой консоль разработчика (F12 → Console)
3. Выполни:

```javascript
addElement("neon", "Неон", "💡", "science", "electricity", "gas", "Инертный газ");
```

4. Элемент сразу появится в палитре (если ингредиенты открыты)

5. Экспортируй данные:

```javascript
downloadData();
```

Файл `alchemy-data-export.json` скачается — импортируй элементы и рецепты оттуда в `data/elements.json` и `data/recipes.json`.

## 🎨 Иконки

### Эмодзи (по умолчанию)
Просто укажи эмодзи в поле `icon`.

### SVG-иконка
1. Добавь SVG в `data/icons.json`:

```json
{
  "neon": "<svg class='game-icon' viewBox='0 0 64 64'>...</svg>"
}
```

2. Установи `"iconType": "svg"` в элементе.

### Большая иконка (full)
Для элементов, которые лучше смотрятся как крупный эмодзи без подложки:

```json
{
  "iconType": "full",
  "icon": "🚀"
}
```
