# Состояние проекта «Алхимия»

## Общая картина

Проект состоит из двух сборок:

1. **Standalone** (`alchemy.html`) — один HTML-файл, открывается без сервера. Содержит весь CSS, JS и данные inline.
2. **Модульная** (`alchemy-refactored/`) — разделена на файлы для разработки. Требует локальный сервер.

Обе сборки основаны на **полной версии v1.18.0** со всем функционалом:
- 4 базовых элемента (вода, огонь, земля, воздух)
- Полный набор элементов и рецептов
- Справочник (codex) с поиском и режимами
- Цепочки открытий
- Подсказки
- Настройки
- Счётчики рецептов на чипах
- Drag & drop (мышь + touch)

## Структура файлов

```
.
├── alchemy.html                  ← 🎮 Standalone (играть сразу)
├── build-standalone.py           ← Скрипт сборки standalone из модульной версии
├── README.md                     ← Документация для контрибьюторов
├── alchemy-refactored/           ← 🛠️ Модульная версия
│   ├── index.html                ← Точка входа (нужен сервер)
│   ├── css/styles.css            ← Стили
│   ├── js/game.js                ← Весь игровой код (данные + логика + UI)
│   ├── publish.py                ← Скрипт публикации
│   ├── README.md                 ← Документация
│   └── CODEMAP.md                ← Карта кода
```

## Ключевые решения

- **Данные встроены в JS** — в v1.18.0 данные хранятся внутри `game.js` как константы (`E`, `R`, `CATS`, `ICONS` и т.д.), а не в отдельных JSON-файлах.
- **build-standalone.py** просто встраивает CSS и JS в index.html — никаких fetch, никакой сложной логики.
- **Старая урезанная рефакторизованная версия удалена** — была заменена на полную v1.18.0.

## Как собрать standalone

```bash
python build-standalone.py
```

## Как запустить модульную версию

```bash
cd alchemy-refactored
python -m http.server 8000
# Открыть http://localhost:8000
```
